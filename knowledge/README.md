# Knowledge Base

KB articles live under:

`knowledge/<device type>/<operating system>/<application>/issue.md`

Example:

`knowledge/endpoint/windows/microsoft_defender/device_is_slow_or_freezing/issue.md`

Notes:
- Folder names should be lowercase and use underscores.
- Each `issue.md` should describe **one** specific problem and its resolution steps.
- The ingestion pipeline infers taxonomy (device/os/application) from the folder path.
