# Passcode Out of Sync

# Duo Security (App Troubleshooting)

Use this guide to resolve issues where the offline 6-digit passcodes generated by the Duo Mobile app are being repeatedly rejected by the login prompt, usually due to the phone's internal clock drifting out of sync with the Duo servers.

### Passcode Out of Sync

## Severity:
`S3` — Minor degradation; user cannot log in while offline or in areas with poor cellular service.

## Symptoms
- The user types the 6-digit code displayed in the Duo Mobile app, but the prompt says "Incorrect passcode. Please try again."
- Push notifications work perfectly, but offline codes fail consistently.
- The user recently traveled across multiple time zones or manually changed their phone's date and time settings.

## Quick checks
- Verify the user is not accidentally reading the passcode for a personal account (like Instagram or GitHub) stored in the same Duo app.
- Check if the user is typing the code quickly before the timer bar turns red and generates a new one.

## Fix steps
1. (For iOS/Apple) Instruct the user to open the iPhone Settings app, go to General, then Date & Time. Ensure Set Automatically is toggled On.
2. (For iOS/Apple) Open the Duo Mobile app, tap the menu icon (three lines) in the top left, tap Settings, and tap Reconnect under the account name.
3. (For Android) Open the Android Settings app, go to System, then Date & time. Ensure Set time automatically is toggled On.
4. (For Android) Open the Duo Mobile app, tap the menu icon (three dots) in the top right, tap Settings, scroll down, and tap Duo Mobile Settings. Tap Sync Passcodes.
5. Generate a brand new 6-digit code in the app and test it on the login prompt.

## Escalate if
- The clock is set automatically, the app is synced, but the passcodes are still rejected.
- The user is using a physical hardware token (like a Duo D-100 key fob) instead of a smartphone, and the codes are failing. (Hardware tokens must be resynced manually by an administrator in the Duo Admin Panel).

## Ticket fields to capture (when escalating)
- Mobile OS: (e.g., Android 14)
- Device Type: (Smartphone App vs. Physical Hardware Token)
- Travel History: (Did the user recently change time zones?)
